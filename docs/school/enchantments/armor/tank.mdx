---
title: Panzerung
---

Mit <strong>Panzerung</strong> erhältst du pro Rüstungsteil und der jeweiligen Stufe, eine höhere Anzahl an maximaler Herzen.

### Herzen pro Stufe

| Stufe    | Anzahl an max. Herzen |
|----------|-----------------------|
| X (10)   | 5                     |
| IX (9)   | 4.5                   |
| VIII (8) | 4                     |
| VII (7)  | 3.5                   |
| VI (6)   | 3                     |
| V (5)    | 2.5                   |
| IV (4)   | 2                     |
| III (3)  | 1.5                   |
| II (2)   | 1                     |
| I  (1)   | 0.5                   |
* Die Anzahl kann sich variieren, je nachdem ob es auf mehreren Rüstungsteilen drauf ist und je nach der Stufe.

### Anwendbar auf:
- Netherite Rüstung
- Diamant Rüstung
- Gold Rüstung
- Ketten Rüstung
- Eisen Rüstung
- Leder Rüstung
