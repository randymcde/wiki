# 📜 Tutorial

Die **Tutorial** Quest bringt dir alles bei, was du auf dem Server brauchst – von der Mine bis zur Warzone.

---

## ⛏️ Chapter 1 – Mine

In diesem Kapitel wird der der Start in den Minen gezeigt. Minen sind eine Möglichkeit um an Gems und Erfahrungspunkte zu kommen.

| # | Aufgabe                                            |
|---|----------------------------------------------------|
| 1 | Besuche den **Minen-Händler**                       |
| 2 | Besuche eine **Mine** deiner Wahl                  |
| 3 | Farme eine bestimmte Anzahl **Blöcke** in der Mine |
| 4 | Verkaufe Gegenstände bei einem **Händler**         |
| 5 | Verdiene eine bestimmte Anzahl an **Gems**         |
| 6 | Kaufe mindestens eine neue **Mine**                |

:::tip Wo muss ich hin?
Der **Minen-Händler** wird **gelb** in deiner Locator Bar angezeigt, während du auf einem Hub Server bist.
:::

---

## 🟣 Chapter 2 – Plots

In diesem Kapitel wird dir gezeigt wie du an ein Grundstück kommst. Auf diesem kannst du Gegenstände lagern und gestalten wie du es möchtest.
Ebenfalls kannst du mit Freunden zusammen auf einem Grundstück spielen.

| # | Aufgabe                             |
|---|-------------------------------------|
| 1 | Finde das **Plot Portal** am Spawn  |
| 2 | Besuche die **Plot Welt**           |
| 3 | Kaufe mindestens ein **Grundstück** |

:::tip Wo muss ich hin?
Das **Plot Portal** wird **gelb** in deiner Locator Bar angezeigt, während du auf einem Hub Server bist.
:::

---

## ⚔️ Chapter 3 – Warzone

In diesem Kapitel wird dir gezeigt wie du in die Warzone kommst. Ebenfalls ist auch eine kleinere Challenge dabei. :)

| # | Aufgabe                                    |
|---|--------------------------------------------|
| 1 | Finde den **Zug** am Spawn                 |
| 2 | Betrete den **Zug**                        |
| 3 | Töte eine bestimmte Anzahl an **Spielern** |

:::tip Wo muss ich hin?
Der **Zug** wird **gelb** in deiner Locator Bar angezeigt, während du auf einem Hub Server bist.
:::
