---
title: Duplikat
---

<strong>Duplikat</strong> gibt dir in den Minen eine Chance darauf, das der abgebaute Block/Erz dupliziert. (Bzw. die Erze)

### Chancen zum "aktivieren"

| Stufe    | Chance |
|----------|--------|
| X (10)   | 30%    |
| IX (9)   | 27%    |
| VIII (8) | 24%    |
| VII (7)  | 21%    |
| VI (6)   | 18%    |
| V (5)    | 15%    |
| IV (4)   | 12%    |
| III (3)  | 9%     |
| II (2)   | 6%     |
| I  (1)   | 3%     |

### Anwendbar auf:
- Netherite Werkzeuge
- Diamant Werkzeuge
- Gold Werkzeuge
- Eisen Werkzeuge
- Stein Werkzeuge
- Holz Werkzeuge
